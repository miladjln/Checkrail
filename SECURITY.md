## Reporting a Vulnerability

Security is paramount in AI agent governance. If you discover a security vulnerability or guardrail bypass mechanism in Agent Opt:

1. **Do not create a public issue.**
2. Please report the security vulnerability privately by contacting **Seyed Milad Jalilian** via GitHub private vulnerability reporting or direct email.
3. Include details of the vulnerability, reproduction steps, and potential impact.

We will acknowledge receipt within 48 hours and coordinate a timely fix and responsible disclosure.
